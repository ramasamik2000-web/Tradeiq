# TradeIQ Free v0.5

A free, password-protected research prototype for NSE/BSE symbols, with 5-minute/daily/weekly historical candles, EMA20, RSI14, MACD, ATR and rule-based BUY CANDIDATE / SELL CANDIDATE / WAIT assessments. Headlines are linked from Google News RSS. Groww execution is manual.

## Limitations (read before trading)
- Yahoo Finance via `yfinance` is unofficial, may be delayed, rate-limited or unavailable, and is **not** a guaranteed live NSE/BSE market feed.
- Intraday 5-minute candles are available only over a limited historical window and may lag.
- No continuous scanning, alerts, real-time streaming, portfolio sync, validated predictive AI, news sentiment model, or guaranteed complete NSE/BSE coverage.
- The "AI assessment" is **transparent deterministic technical rules**, not a trained AI model. Trade levels are illustrative ATR-derived references, not actionable advice. No backtesting has been performed.
- A free Render service can sleep and has ephemeral storage. This app deliberately stores no user portfolios or credentials in a database.
- No payment is needed for the included code. Free hosting provider limits can change.

## Local Windows setup
Use Python 3.13. In PowerShell inside the extracted folder:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:TRADEIQ_PASSWORD = "choose-a-long-unique-password"
$env:SESSION_SECRET = "replace-with-a-random-32-plus-character-secret"
.\.venv\Scripts\python.exe -m uvicorn app:app --reload
```

Open http://127.0.0.1:8000. Do not commit or share these secrets.

## Deploy to Render (free tier where available)
1. Upload the extracted project contents (not the ZIP) to your GitHub repository. `.gitignore` excludes `.env`, local DBs and virtual environments.
2. In Render, choose **New > Blueprint** and connect the GitHub repository containing `render.yaml`. Confirm the selected plan is **Free** before creating anything; never enter payment details if you require zero cost.
3. Supply `TRADEIQ_PASSWORD` as a strong, unique password in Render environment variables. `SESSION_SECRET` is generated by Render according to `render.yaml`.
4. Set `COOKIE_HTTPS=1` in Render environment variables so the session cookie is HTTPS-only.
5. After deployment, open the generated `https://...onrender.com` address and sign in.
6. If Render does not offer a free plan for your account, stop rather than selecting a paid plan.

## Security
This is a single-password personal prototype, **not production-grade identity management**. For public internet deployment, add rate limiting, proper user accounts/MFA, CSRF protection, monitoring and a security review. Do not use a password reused on other services.
